# e-scripts

面向 E-Hentai、ExHentai 与 HentaiVerse 的 userscript 工作区。可安装脚本位于仓库根目录，详细功能、权限、测试方法和版本记录位于 [`readme/`](readme/)；独立测试位于 [`test/`](test/)，项目资源位于 [`resource/`](resource/)。

`reference/` 中的第三方参考脚本与 `.agents/` 本地开发规范不会上传到公开仓库。本仓库暂不附加统一开源许可证。
